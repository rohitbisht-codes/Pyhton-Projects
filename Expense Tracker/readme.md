# 💰 Expense Tracker (Python)

A simple Expense Tracker built using Python and File Handling.

## 📌 Features

* ➕ Add Expense
* 📋 View All Expenses
* 🔍 Search Expense
* 💰 Calculate Total Spending
* 💾 Store data permanently using a text file (`expenses.txt`)

## 🛠 Technologies Used

* Python 3
* File Handling (`read`, `write`, `append`)
* Conditional Statements (`if`, `elif`, `else`)
* Loops
* String Functions (`split`)
* Type Conversion

## 📂 Project Structure

```
Expense-Tracker/
│── expense_tracker.py
│── expenses.txt
└── README.md
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Run:

```bash
python expense_tracker.py
```
