# Number Utility Toolkit (Python)

A beginner-friendly Python project that performs different number operations using functions and a menu-driven interface.

## Features

- Factorial
- Prime Check
- Palindrome Check
- Armstrong Number Check
- Reverse Number
- Count Digits
- Sum of Digits
- Largest Digit
- Smallest Digit
- Even/Odd Check

## Technologies Used

- Python 3

## How to Run

1. Download the project.
2. Open terminal.
3. Run:

```bash
python main.py
```
